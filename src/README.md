## 📝 Project Overview
This project is a Java implementation of an Employee Management System based on a UML Class Diagram. It demonstrates core Object-Oriented Programming (OOP) concepts such as Inheritance, Polymorphism, Encapsulation, and Abstraction.

### Key Components:
- **`model.Employee`**: Abstract base class representing general employee attributes and abstract method `calculateSalary()`.
- **`model.MonthlyEmployee`**: Subclass calculating salary with bonuses and deductions.
- **`model.HourlyEmployee`**: Subclass calculating salary based on hourly rate and hours worked.
- **`model.CommissionEmployee`**: Subclass calculating salary with base salary and sales commission.
- **`model.Department`**: Manages a list of employees and calculates the total departmental salary budget.
- **`model.Gender`**: Enum defining employee gender (`MALE`, `FEMALE`).
